# Dynamic Web Application & Management System

A dynamic, database-driven web application and content management system developed using **PHP**, **MySQL**, **JavaScript**, and **CSS**.

---

## 🌟 Overview
This project provides a complete personal website and dynamic management panel. It allows administrative users to manage site settings, pages, personal details, education history, and skills dynamically through a centralized dashboard.

---

## ✨ Features
* **Admin Dashboard & Authentication:** Secure login interface (`login.php`) for administrative management.
* **Modular Page Management:** Modular layout architecture (`include/`, `pages/`, `sistem/`) for dynamic content rendering.
* **Dynamic Content Sections:** Dynamic configuration of personal information, front-page settings, education background, and skill sets.
* **Responsive UI:** Custom styling built with modern CSS and JavaScript components for cross-device compatibility.
* **Asset Upload Handling:** Dedicated directories for handling user-uploaded assets and media.

---

## 🛠️ Tech Stack
* **Backend:** PHP (Native / Procedural & OOP)
* **Database:** MySQL
* **Frontend:** HTML5, CSS3, JavaScript
* **Server Environment:** Apache (XAMPP)
